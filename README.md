# Java Banking Management System

A robust, console-based Banking Management System built in Java. This project demonstrates fundamental Object-Oriented Programming (OOP) concepts, secure state management, and reliable data validation applied to core financial workflows.

## 🚀 Key Features

* **Secure Transactions:** Clean logic handling deposits and withdrawals with real-time balance modifications.
* **Overdraft & Edge-case Protection:** Built-in business rules preventing negative transactions or overdraft attempts.
* **Dynamic Audit Trail:** Tracks all interactions to generate an inline, readable transaction history statement.
* **Robust Input Validation:** Standardized terminal scanning that filters out malicious or invalid data entry types without system failures.

## 🛠️ Architecture & Concepts Demonstrated

* **Strict Encapsulation:** Account data (`balance`, `transactionHistory`) is hidden using `private` access modifiers to secure data integrity.
* **Parameter Passing:** Demonstrates clean variable scoping and safe value mapping across utility modules.
* **OOP Modular Design:** Separates the data schemas (`BankAccount`) from execution architectures (`Main` runtime ecosystem).

## 💻 Technical Requirements

* **Java Development Kit (JDK):** Version 8 or higher
* **Text Editor / IDE:** IntelliJ IDEA, Eclipse, VS Code, or a standard terminal shell.

## ⚙️ Quick Start & Installation

1. **Clone the Repository:**
   ```bash
   git clone https://github.com
   ```

2. **Navigate to the Project Directory:**
   ```bash
   cd YOUR_REPOSITORY_NAME
   ```

3. **Compile the Source File:**
   ```bash
   javac Main.java
   ```

4. **Run the Application:**
   ```bash
   java Main
   ```
