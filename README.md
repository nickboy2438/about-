Chromosomal Disorders is an educational web-based project designed to provide simple and easy-to-understand information about common chromosomal disorders and their genetic causes.

The project explains how chromosomes, DNA, and genes are related to genetic information and how changes in chromosome number can lead to various chromosomal disorders.

It covers important disorders such as:

Down Syndrome
Edwards Syndrome
Patau Syndrome
Turner Syndrome
Klinefelter Syndrome

The project presents the information using tables, descriptions, and karyotype information, making it useful for students studying Genetics, Biology, Biotechnology, and related subjects.

🎯 Objectives

The main objectives of this project are:

To introduce the concept of chromosomes and genetic information.
To explain the relationship between DNA, genes, and chromosomes.
To identify common chromosomal disorders.
To explain the chromosomal changes responsible for each disorder.
To provide the corresponding karyotypes.
To make genetic concepts easier to understand through a simple presentation.
To create an accessible educational resource for students.
